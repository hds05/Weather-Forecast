# weather-Forecast

This project is about Weather Forecast. In Allows user to search about weather forecast by city name or they can search for their current location. All the data will be saved inside the local storage. A dropdown will be created next to input box getting that data from local storage. Used Icons to show temperature, humidity and wind. Applied toggle functionality for current city's temperature. 
Date will be shown on the capital of India only. (Default city- Delhi).


##Features
- Integration with Weather API
- Location-Based Forecast
- User can search for weather forecasts by city name.
- User can search weather forecasts for their current location.
- A dropdown of the searched cities.
- Extended weather forecasts for multiple hours or days (e.g., 5-day forecast).
- Location-specific weather forecasts.
- Temperature unit toggle (°C/°F) on today's temprature.
- Responsive on multiple devices.
- Interactive UI.
- Background change based on weather.
